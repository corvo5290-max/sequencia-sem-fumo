# Site de apoio e acompanhamento

## Testar localmente
Abra `index.html` em um navegador ou publique todos os arquivos desta pasta no GitHub Pages.

## Novidades desta versão
- Seleção de objetivo e meta pessoal.
- Página para registrar situações, emoções, intensidade da vontade e estratégias.
- Histórico de gatilhos armazenado no localStorage do navegador.
- Página de ajuda com buscas dinâmicas por CAPS AD e clínicas no Google Maps e link para informações do SUS.

## Privacidade e limites
Os registros ficam no navegador deste dispositivo e não são enviados a um servidor. Pessoas com acesso ao mesmo perfil do navegador podem potencialmente vê-los; evite dispositivos compartilhados. Limpar os dados do navegador pode apagar os registros.

Os mapas fazem buscas dinâmicas e não constituem uma lista verificada de serviços. Confirme endereço, horários, faixa etária e atendimento diretamente com cada unidade. O site não substitui profissionais de saúde nem atendimento de emergência. Em emergência no Brasil, ligue 192 (SAMU).
